# AttackTrafficGenerator

Kho lưu trữ các kịch bản diễn tập APT phục vụ kiểm thử và đánh giá khả năng phát hiện tấn công.

## Nội dung

| Thư mục | Định dạng | Mô tả |
|---|---|---|
| `ART_YAML_Scenarios/` | Atomic Red Team YAML | Kịch bản theo chuẩn ART |
| `CALDERA_YAML_Scenarios/` | CALDERA Stockpile YAML | Kịch bản theo chuẩn CALDERA |

## Đóng góp kịch bản

Chỉ chấp nhận file `.yml` / `.yaml` đúng định dạng tương ứng với từng thư mục.  
Xem thêm cấu trúc mẫu trong từng thư mục trước khi tạo kịch bản mới.

## Liên quan

Các kịch bản trong repo này được tích hợp vào [MITRE-ATTACK-Mapper](https://baodeptraii.github.io/MITRE-ATTACK-Mapper/) để mapping tự động sang MITRE ATT&CK framework.
